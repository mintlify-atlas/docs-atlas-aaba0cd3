---
title: /optimize Command
description: Perform comprehensive SEO audit and final optimization pass before publishing
---

The `/optimize` command performs a final SEO optimization pass on completed articles, validating all elements meet best practices.

## Usage

```bash
/optimize [article file]
```

<ParamField path="article file" type="string" required>
  Path to the article file to optimize (in `drafts/` or `rewrites/`)
</ParamField>

## Examples

```bash
/optimize drafts/content-marketing-strategies-2025-03-04.md
```

```bash
/optimize rewrites/podcast-guide-rewrite-2025-03-04.md
```

## What It Does

### Comprehensive SEO Audit

<Tabs>
  <Tab title="Keyword Analysis">
    **Primary Keyword Density**: 1-2% throughout article
    
    **Keyword Placement Check**:
    - In H1 headline ✓
    - In first 100 words ✓
    - In 2-3 H2 headings ✓
    - In meta title ✓
    - In meta description ✓
    - In URL slug ✓
    
    **Semantic Variations**: Related keywords used naturally
    
    **Keyword Stuffing**: No over-optimization detected
    
    **LSI Keywords**: Latent semantic keywords present
  </Tab>
  
  <Tab title="Heading Structure">
    **H1**: Only one H1, includes primary keyword
    
    **H2s**: 4-7 H2 sections, at least 2-3 with keyword variations
    
    **H3s**: Proper nesting under H2s, descriptive and keyword-rich
    
    **Hierarchy**: Logical progression, no skipped levels
    
    **Length**: Headings descriptive but concise
  </Tab>
  
  <Tab title="Content Quality">
    **Word Count**: 2000+ words (2500-3000+ preferred)
    
    **Paragraph Length**: Average 2-4 sentences
    
    **Sentence Length**: Varied, averaging under 25 words
    
    **Readability Score**: 8th-10th grade level (Flesch-Kincaid)
    
    **Active Voice**: Predominantly active voice
    
    **Transition Words**: Smooth flow between sections
    
    **Formatting**: Bold, italics, lists used appropriately
  </Tab>
</Tabs>

### Link Optimization

<Steps>
  <Step title="Internal Links (3-5+ required)">
    - Count current internal links
    - Verify contextual relevance
    - Check keyword-rich anchor text
    - Ensure natural integration
    - Validate variety (pillar, blog, product, resources)
    - Cross-reference `context/internal-links-map.md`
    - Test for broken links
  </Step>
  
  <Step title="External Links (2-3+ required)">
    - Count external authority links
    - Verify authoritative sources
    - Ensure relevance to content
    - Check link freshness
    - Test all external links
    - Verify appropriate nofollow usage
  </Step>
</Steps>

### Meta Element Optimization

<ParamField path="Meta Title" type="string">
  **Requirements**:
  - Length: 50-60 characters
  - Primary keyword included naturally
  - Compelling and click-worthy
  - Consider adding brand name
  - Distinct from other page titles
  
  **Output**: 3-5 optimized alternatives with recommendations
</ParamField>

<ParamField path="Meta Description" type="string">
  **Requirements**:
  - Length: 150-160 characters
  - Primary keyword included
  - Clear value proposition
  - Call-to-action phrase
  - Encourages SERP click
  - Doesn't cut off mid-sentence
  
  **Output**: 3-5 optimized alternatives with recommendations
</ParamField>

<ParamField path="URL Slug" type="string">
  **Requirements**:
  - Concise but descriptive
  - Primary keyword included
  - Lowercase, hyphens between words
  - 3-5 words ideal
  - No stop words unless necessary
  
  **Output**: Evaluation and alternative if needed
</ParamField>
