The `/rewrite` command updates and improves existing content based on analysis findings, competitive changes, or content decay.

## Usage

```bash
/rewrite [topic or analysis file]
```

<ParamField path="topic" type="string" required>
  The topic to rewrite or path to analysis file from `/analyze-existing`
</ParamField>

## Examples

```bash
/rewrite product comparison
```

```bash
/rewrite marketing guide
```

## What It Does

### Pre-Rewrite Review

1. **Reads existing article** thoroughly
2. **Reviews analysis report** from `/analyze-existing` if available
3. **Checks research brief** for updated angles
4. **Verifies brand voice** alignment with `context/brand-voice.md`
5. **Applies SEO guidelines** from `context/seo-guidelines.md`
6. **Understands competitive changes** in SERP

### Rewrite Strategy

Determines scope based on analysis:

<Tabs>
  <Tab title="Light Update (20-30%)">
    - Fix outdated statistics
    - Add missing keywords
    - Improve meta elements
    - Update examples
    - Add internal links
  </Tab>
  
  <Tab title="Moderate Refresh (40-60%)">
    - Restructure sections
    - Expand content significantly
    - Update all examples
    - Rewrite introduction
    - Add new H2 sections
  </Tab>
  
  <Tab title="Major Rewrite (70-90%)">
    - New outline structure
    - Significant content expansion
    - Fresh angle or perspective
    - Complete SEO overhaul
    - New supporting data
  </Tab>
  
  <Tab title="Complete Overhaul (90%+)">
    - Essentially new article
    - Same topic, new approach
    - Full competitive repositioning
    - Comprehensive update
  </Tab>
</Tabs>

## Rewrite Process

<Steps>
  <Step title="Determine What to Keep">
    - Sections still accurate and comprehensive
    - Unique insights that remain valuable
    - Well-performing structure or formatting
    - Relevant examples or case studies
    - Appropriate internal links
  </Step>
  
  <Step title="Determine What to Update">
    - Outdated statistics with current data
    - Old screenshots or examples
    - Deprecated terminology or processes
    - Missing keywords in headings and body
    - Weak meta title/description
    - Insufficient internal links
  </Step>
  
  <Step title="Determine What to Add">
    - New sections for competitive content gaps
    - Recent industry trends or developments
    - Additional examples or use cases
    - Better introduction hook
    - Stronger conclusion and CTA
    - Missing SEO elements
  </Step>
  
  <Step title="Determine What to Remove">
    - Deprecated/inaccurate information
    - Redundant or repetitive sections
    - Overly promotional language
    - Outdated examples or references
    - Fluff or filler content
  </Step>
</Steps>

## Content Structure

### Updated Headline (H1)

- Optimize with primary keyword if not present
- Refresh if original title is dated or weak
- Maintain if it's strong and still optimized

### Refreshed Introduction

- Update hook with current statistics or trends
- Clarify value proposition if needed
- Ensure primary keyword in first 100 words
- Make it compelling for today's reader

## SEO Enhancement

### Keyword Optimization

<Tabs>
  <Tab title="Primary Keyword">
    - Ensure 1-2% density throughout
    - Add to H2s if missing
    - Confirm appears in first 100 words
  </Tab>
  
  <Tab title="Semantic Variations">
    - Use related keywords naturally
    - Add LSI keywords
    - Avoid keyword stuffing
  </Tab>
</Tabs>

### Internal Linking

<Steps>
  <Step title="Review Existing Links">
    Ensure all internal links still work and are relevant
  </Step>
  
  <Step title="Add New Links">
    Reference newer content published since original
  </Step>
  
  <Step title="Strategic Placement">
    Link to pillar content and related articles (3-5+ links)
  </Step>
  
  <Step title="Anchor Text">
    Use keyword-rich, descriptive anchor text
  </Step>
</Steps>

### External Linking

- **Update broken links** - Replace any dead external links
- **Fresher sources** - Replace old statistics with recent data
- **Authority** - Ensure external links are to credible sources
- **Relevance** - Remove outdated external references

### Meta Elements

<ParamField path="Meta Title" type="string">
  Rewrite if not optimized or compelling (50-60 characters)
</ParamField>

<ParamField path="Meta Description" type="string">
  Refresh to highlight updated content (150-160 characters)
</ParamField>

<ParamField path="URL Slug" type="string">
  Generally keep original to preserve rankings
</ParamField>

## Next Steps

After rewrite completion:

1. **Review change summary** - Ensure all updates are intentional
2. **Compare to original** - Verify improvements
3. **Run optimize** - Use `/optimize` for final polish if needed

```bash
/optimize rewrites/[article-name]-rewrite-2025-03-04.md
```

4. **Publish** - Move to `published/` when ready
5. **Note original URL** - Ensure proper redirect/replacement
